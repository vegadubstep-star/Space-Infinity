# Factory bank reset

The previous 119 factory sounds and their refinement tables have been removed at the owner’s request. The factory list now contains only **Init**, a dry oscillator sound with full sustain and no LFO depth, gate, pumping or effects. New sounds will be programmed from the owner’s next specification.

Existing bank indexes retire all previous factory IDs F0–F119. Init uses F120, so old identities are never reassigned. User-saved files and their ordering remain intact; Init is inserted when an older bank is opened. Restore Factory restores only Init and preserves user sounds.

Saved DAW projects and user presets still recall their stored parameters and embedded audio; deleting a factory listing does not rewrite existing music projects.
