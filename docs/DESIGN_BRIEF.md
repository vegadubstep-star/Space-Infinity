# UI design brief

Product name: **SPACE INFINITY**. Target users: producers of 1990s German hard trance and contemporary electronic music.

**Perspective**: exact orthographic, straight-on view of the front panel; no tilted/3D perspective. The supplied hardware reference picture is for colours, material, switches and manufacturing realism only.

**Materials**: black anodised brushed aluminium, subtle metal grain, shallow CNC panel edges, realistic legends, finely knurled dark rotary caps with satin highlights, tactile red backlit selectors, OLED-like dark displays. Use restrained reflections, no fantasy sparks. Overall minimal, credible professional outboard hardware aesthetic.

**Sections**: Header/preset strip; oscillator 1/2/3 with editable, visibly meaningful waves; multi-mode filter; four-stage AMP and FILTER envelopes with accurate graphs; LFO/modulation; dual FX/send controls, output section; keyboard and pitch/mod controls. Reduce knobs per section, include expert panels on demand.

**Controls**: functional keyboard input; hover labels; wheel and drag support; accessible keyboard navigation when possible; automation/parameter attachment to JUCE APVTS; animated but lightweight live waveform. Resize properly in FL Studio.

Reference files:
- `design/user-hardware-colour-reference.webp` — original styling photo (angle must NOT be copied)
- `design/concept-top-down-inspiration.webp` — style concept ONLY
- `design/actual-browser-interface.webp` — capture of running browser code, current baseline (NOT native VST)

Do not substitute a generated image for a screenshot of an actual running application when reporting progress.
